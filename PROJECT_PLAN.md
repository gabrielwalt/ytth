# Your Track to Health: migration plan

This is the working plan for migrating every page of yourtracktohealth.com into the redesign. It follows the design PDFs and takes the content from the current pages.

**Keep this plan current.**
- When you start a task, tick it in progress; when you finish it, tick it done.
- Add new tasks as they come up.
- Record each work session in the progress log at the end.
- Decisions and open questions live in `PROJECT_OVERVIEW.md`; this file links to them.

Status: `[x]` done · `[~]` in progress · `[ ]` to do · `[?]` needs a decision from the site owner

## The current site in numbers

Figures from `migration-work/site-inventory.json`:
- **178 HTML pages**, about 50,000 words.
- **334 linked PDFs**, with 1,501 links to them.
- **40 pages** in the main nav and 158 in the site map.
- **1 login-gated link**.
- All pages are server-rendered ASP.NET, identified by query string (`Content.aspx?MenuId=N`).
